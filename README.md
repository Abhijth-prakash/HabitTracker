# 🟣 HabitTracker

A full-stack habit tracking application built with the MERN stack.

HabitTracker allows users to create and manage habits, track daily progress, view habit logs, and analyze their progress through weekly reports.

The application uses JWT authentication with HTTP-only cookies and is deployed using Vercel and Render.

## ✨ Features

### 🔐 Authentication

- User registration
- User login
- User logout
- JWT authentication
- HTTP-only authentication cookies
- Protected routes
- User profile
- Secure password hashing using bcrypt

### 📋 Habit Management

- Create new habits
- Edit habits
- Delete habits
- View all habits
- Track habit completion
- Daily habit logging

### 📊 Progress Tracking

- View daily habit progress
- View habit logs
- Weekly reports
- Track completed and missed habits
- Analyze weekly performance
